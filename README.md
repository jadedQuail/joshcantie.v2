# joshcantie.v2

New personal website. Nuxt 4 + Nuxt Content + Tailwind CSS 4.

## Running locally

Requires Node 24.18.0 or newer.

```sh
npm install    # first time only
npm run dev
```

Then open http://localhost:3000.

## Other commands

```sh
npm run generate   # static build, output in .output/public
npm run preview    # serve the built site
```
